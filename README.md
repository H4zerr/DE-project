## Data Engineer Project
Запускаем скрипт start в текущей директории для установок дополнительных папок, загрузок исходных данных для работы, а также в скрипте автоматически поднимется docker-compose, который запустит базу данных, airflow и adminer для работы.

```bash
./start.sh
```

Загрузка скрипта займет время, так как он будет подгружать данные. После того как скрипт отрабтает, будет всё запущено (airflow, adminer, postgresql). 

**При повторных запусках скрипт запускать больше нельзя, надо будет прописывать команду ниже в той же директории:**

```bash
docker-compose up
```

Для поднятия базы данных, нужно будет зайти в интерфейс AirFlow:

[AirFlow](http://localhost:8080/)

**User: airflow**

**Password: airflow**

Затем **ОДИН** раз **ЗАТРИГЕРИТЬ** DAG под названием ***init_db_dag***, после чего ждать большое количество времени, так как создаётся бд и идёт загрузка обработанных данных. После выполнения DAG'a в AirFlow выйдет зелёный сигнал с галочкой, что он отработал и остановился.

P.S. У меня этот DAG занял примерно 50 минут времени.

После загрузки базы данных данными, можно активировать второй DAG под названием ***for_new_jsons_dag***, который уже надо включить на постоянную основу. Он будет с периодичностью 10 минут проверять папку **./data/diploma_extra_dataset** на наличие новых .json файлов, после чего обрабатывать их и добавлять в БД.

Вся эта система подключена к вольюмам, так что после повторных запусков, нужно будет запускать только DAG под названием ***for_new_jsons_dag***, так как работа первого скрипта уже будет сохранена.
